# НГУ · облік особового складу / учёт личного состава

Отдельный проект для административного учёта военнослужащих Национальной гвардии Украины. Гражданская версия и OmniFactory CRM не изменяются.

## Нормативная основа

- [Закон України «Про Національну гвардію України» № 876-VII](https://zakon.rada.gov.ua/laws/show/876-18).
- [Наказ МВС № 73 від 30.01.2017: Інструкція з організації обліку особового складу НГУ](https://zakon.rada.gov.ua/laws/show/z0248-17). Основной акт для реестра и печатных форм.
- [Закон України «Про військовий обов'язок і військову службу» № 2232-XII](https://zakon.rada.gov.ua/laws/show/2232-12).
- [Закон України «Про захист персональних даних» № 2297-VI](https://zakon.rada.gov.ua/laws/show/2297-17).

Точную действующую редакцию, приложения и реквизиты каждой официальной формы необходимо проверить перед публикацией формы. Русский язык используется только для интерфейса и внутренних черновиков, официальный украинский текст не переводится.

## Статус

Локальная ветка `feature/ngu-personnel`. Реализован демонстрационный интерфейс на вымышленных записях; программа для реальных персональных данных не выпущена. Ветка не связана с удалённым репозиторием пользователя.

## Первый релиз

Карточка личного состава, журнал приказов и кадровых событий, должностная история, административные периоды, документ-основание, двуязычный интерфейс, роли и аудит, внутренние печатные отчёты. Официальные бланки подключаются по одному после сверки конкретных приложений приказа № 73.

Не включены сведения о боевых задачах, маршрутах и точном местонахождении личного состава.

## Запуск прототипа в PowerShell (отдельная папка)

```powershell
cd C:\Users\bonda\PycharmProjects
Expand-Archive "$env:USERPROFILE\Downloads\NGU_Personnel_CRM_branch_foundation.zip" -DestinationPath . -Force
cd .\ngu_personnel_crm
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m uvicorn ngu_crm.app:app --host 127.0.0.1 --port 8073
```

Открыть `http://127.0.0.1:8073/`. Для остановки нажать `Ctrl+C`. Демо-база `demo.db` создаётся в этой папке при запуске. Если архив имеет другое имя, подставьте его фактический путь. Не копируйте эти файлы в `Food_Porn` или `omnibot_crm`.
